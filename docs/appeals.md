# Appeals

If you disagree with a rejection, revocation, suspension or delisting, open an issue in this repository using the
**Appeal a decision** form. Give:

- the project id;
- the release, if the decision is about one;
- the decision's public reason, as shown in the launcher or the index;
- why you believe it should change.

Where possible, the appeal is reviewed by a moderator who did not make the original decision. Appeals are public, so
keep private details out of the issue; a moderator will contact you if more is needed.
